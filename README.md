In this lesson, I consolidated the use of Flexbox and learned how to adjust div sizes and display properties.   

```css

  background-color: hsl(0, 0%, 100%);
  width: 800px;
  border-radius: 10px;
  overflow: hidden;
  justify-content: left;
  display: flex;
  margin: 120px auto;
}
```
